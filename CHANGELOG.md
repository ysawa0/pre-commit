# Changelog

## 0.2.0 - 2026-08-31

### Added

- `anti-slop`, a deterministic and dependency-free Markdown and MDX prose linter.
- Twenty-five explainable rules covering filler, canned phrases, rhetorical repetition, rhythm, and formatting density.
- Recommended and strict presets, JSON configuration, local suppressions, and text, JSON, and GitHub output.
- Offset-preserving Markdown projection that ignores code, URLs, front matter, comments, quotations, tables, and structural markup.
- Coffee before-and-after calibration articles and a documented false-positive tuning pass.
- Twenty-four unit and CLI tests.

### Changed

- Updated the repository hook catalog and documentation.
- Replaced the stale Python 2 and 3.5 CI setup with pinned GitHub Actions and automated, test-gated releases.
